## 📦 How to Run Locally

### 1. Prerequisites
Ensure you have **Node.js (v18+)** installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```

## 🌐 How to Deploy on Vercel

### Method A: Deploy via Vercel Web Dashboard (Recommended)

1. Push your repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial commit for NEONVERSE portfolio"
   git branch -M main
   git remote add origin https://github.com/himanshutiwari/NEONVERSE.git
   git push -u origin main
   ```
2. Navigate to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** &rarr; **"Project"**.
4. Import your `NEONVERSE` repository from GitHub.
5. Vercel automatically detects **Next.js**:
   - **Framework Preset:** Next.js
   - **Build Command:** `next build`
   - **Output Directory:** `.next`
   - **Install Command:** `npm install`
6. Click **"Deploy"**. Your site will be live within 1 minute with global CDN and SSL!

### Method B: Deploy via Vercel CLI

1. Install Vercel CLI globally:
   ```bash
   npm i -g vercel
   ```
2. Run deployment from project root:
   ```bash
   vercel
   ```
3. For production deployment:
   ```bash
   vercel --prod
   ```
